Privacy policy

Last updated: 9 November 2026

This policy describes how the app Zero Giri (formerly "Prezzi Carburanti", "the app") handles users' data. The app is developed by Luca De Leo, who can be contacted at luca.deleo@gmail.com.

In short

  • The app requires no registration or account: the Zero Giri server recognises it only by a randomly generated anonymous code.
  • Location is used to search for nearby fuel stations: it is sent for the search, and is neither stored nor used for any other purpose. You can also grant approximate location only.
  • Only if you use parking spot reports, the point of the spot you left is kept on the server for at most 30 days, linked only to the anonymous code; other users see it on the map for a few minutes, without knowing who reported it.
  • There are no ads, analytics, crash reporting or tracking systems.

Location

The app asks for permission to access precise location only while in use (never in the background). You can also grant approximate location only, which the operating system shifts by a couple of kilometres: the station search still works, parking spot reports do not (see below). Location is used to:

  • search for nearby stations: the coordinates of the search point are sent to the Zero Giri server, which returns stations and prices from the Ministry's open data, and to the service of the Italian Ministry of Enterprises and Made in Italy (carburanti.mise.gov.it), which returns real-time prices;
  • show the street and town name (only the town with approximate location): the coordinates are passed to the operating system's geocoding service (on Android, normally provided by Google);
  • report a parking spot you have just left and see those reported by others, as described in "Parking spot reports".

If permission is not granted the app still works: you can search for a town or an address, or pick a point on the map. In this case the searched text is passed to the operating system's geocoding service and the coordinates of the chosen place to the Zero Giri server and to the Ministry's service.

Zero Giri server

The developer's server (zerogiri.lucadeleo.it) provides the app with the Ministry's fuel open data, the app configuration and, when enabled, parking spot reports.

  • Anonymous device code: on first launch the app obtains a random identifier and a secret code from the server, keeps them in the phone's encrypted storage and uses them to access the server. They are not linked to name, email, phone number or other device identifiers. The server keeps the identifier, a fingerprint (hash) of the secret code, the registration date and the date of last access.
  • Searches: for each search the server receives the coordinates of the search point, the radius and the fuel, and replies with the stations in the area. Searches are not stored.
  • Parking: the reports and answers described in "Parking spot reports", with the related counters.
  • IP address: as with any website the server receives the IP address, used only in memory to limit the number of requests and not recorded. The server is reached through Cloudflare, which handles traffic and abuse protection according to its own policy.
  • The server logs contain no coordinates, IP addresses or device codes.

Data sent to third parties

Besides the Zero Giri server, the app communicates only with these services, and only for the stated purposes:

  • Ministry of Enterprises and Made in Italy: coordinates of the search point and radius (real-time prices), station identifier (details).
  • OpenStreetMap Foundation: the map tiles of the displayed area; as with any website, the server receives the device's IP address.
  • Overpass API (overpass-api.de, a service that queries OpenStreetMap data), only if "Usa i dati di OpenStreetMap" (Use OpenStreetMap data) is on in the advanced settings: the coordinates of the stations found, to learn the type of road and area and estimate the travel time. The user's location is not sent; the server receives the device's IP address.
  • Operating system geocoding service: coordinates or searched text, to obtain place names and addresses.
  • Navigation app (e.g. Google Maps or Waze), only if you use "Portami qui" or "Portami lì" (Take me there): it receives the location of the chosen station or parking spot.
  • App chosen for sharing, only if you use "Condividi" (Share): it receives the text with the station's data.

Each service processes data according to its own policy.

Data stored on the device

The app stores only on the device:

  • the chosen settings, including the car category;
  • the favourite stations;
  • the anonymous device code, in the phone's encrypted storage;
  • a copy of the stations and prices of the areas already searched (Ministry open data and latest real-time prices), to keep working when the services do not respond or there is no connection;
  • the type of road and area of the stations received from OpenStreetMap, to avoid requesting it on every search;
  • whether to show free parking spots on the map.

This data contains no personal information and the app does not send it to anyone. If Android backup is enabled on the phone, the operating system may include settings and favourites in the user's Google account backup, as for other apps. Downloaded data can be deleted at any time with "Svuota cache" (Clear cache) in the settings; everything is deleted by uninstalling the app.

Permissions required

  • Precise and approximate location, only while in use: to search for nearby stations and to report parking spots. You can grant approximate location only: the operating system then provides a location shifted by a couple of kilometres, which is enough for stations but not to point out a parking spot.
  • Internet access and network state: to download stations and prices, and to avoid requests when there is no connection.

Libraries and SDKs in the app

The app contains no advertising, analytics or crash reporting SDKs, nor Firebase or Google Play Services. It only uses libraries that run on the device:

  • .NET MAUI and AndroidX / Material Components libraries (Microsoft, Google): the app's user interface and encrypted storage;
  • CommunityToolkit.Maui and CommunityToolkit.Mvvm (.NET Foundation): user interface components;
  • Mapsui, BruTile, NetTopologySuite, SkiaSharp: drawing the map and the OpenStreetMap tiles;
  • sqlite-net and SQLite: local storage of downloaded data;
  • Glide: image loading.

None of these libraries sends data to third parties on its own; the app's communications are only those listed above.

Parking spot reports

With parking spot reports, whoever leaves a parking spot points it out to other users, who see it on the map for a few minutes. It is optional: it is used only by tapping "Ho lasciato il posto" (I've left the spot) or by answering about a spot, and it requires precise location, which the app asks for only at that moment, after a screen explaining why it is needed. No report is ever sent automatically, and nothing happens in the background.

What data. The server receives and keeps:

  • when you tap "Ho lasciato il posto": the coordinates of the spot (the phone's location at that moment), its uncertainty in metres, the date and time, the anonymous device code;
  • when you answer "Ci ho parcheggiato" (I parked there) or "Era occupato" (It was taken): the answer, the date and time, the anonymous device code. The location of whoever answers is sent only to check that they are near the spot and is not stored;
  • for each anonymous code, three counters: spots reported, spots confirmed by others with "Ci ho parcheggiato", spots reported as taken.

While the map of free spots is open, the app sends the server the centre of the displayed area (or, until the map is ready, the phone's location) to receive the nearby spots; these requests are not stored. The distance to the spot is calculated on the phone.

No licence plate, car model, name or other personal data is collected, nor any history of movements: the server receives a point only when the user reports or answers.

Why. To show other users the nearby free spots; to estimate the probability that a spot is still free, based on how much time has passed and on how many reports from the same anonymous code turned out to be right; to limit abuse and repeated reports; to show whoever reports how many people they have helped, with an estimate of the kilometres and CO2 avoided.

Who sees it. Other users see on the map only the location of the spot and how long ago it was reported, not who reported it. Whoever reported a spot sees it marked as their own.

How long. A spot stays visible on the map for a few minutes (5 with the current settings), or until someone answers. Reports and answers are deleted after 30 days; only anonymous counts by area (cells of about 1.2 × 0.6 km) and by hour (day and hour) remain, which do not allow tracing back to the device or to the exact point. The counters remain linked to the anonymous code. Uninstalling the app deletes the code from the phone: the data left on the server can no longer be linked to anyone, and reports are deleted after 30 days anyway. For any request, write to luca.deleo@gmail.com.
